# Marketing & store-listing audit

The lowest-effort growth loop for a **consumer** app on the stores. Applies to Parallax / SplitUPI /
Chitrix and the like.

**Does NOT apply to Oric.** Oric is a mandi/fruit-trading finance tool sold face-to-face to local
traders — it does not grow through Google/SEO/app-store search, so skip this whole file for it. For
Oric the "marketing" audit is: is there a one-page explainer + a live demo running on Balaji Fruit
Co's real data to show the next trader? That's it.

## The loop (consumer apps)

1. **Landing page** for the app — one page, clear value, a store button.
2. **Put that URL in the Play Store / App Store listing.**
3. **Submit the page to Google Search Console + Bing Webmaster** so you can track impressions.
4. **Once impressions come in, build more pages around what people actually search**, and optimise.
5. **Localise to 10+ more languages** (dates/numbers formatted per locale).
6. **Iterate.** Track which pages send people to the store listing — that signals what to expand and
   translate first.

## Store-listing basics to check

- App name, short + full description written for the query a real person types, not jargon.
- Icon and screenshots that read on a phone; a feature graphic where required.
- Privacy policy URL present (stores reject without it — see `legal.md`).
- Data-safety / privacy declarations filled honestly (Play Data safety, App Store privacy labels).
- Correct category, contact email, and a working support URL.
- OG / meta tags + an OG image so shared links look right.

Source: pasted tip, 19 Oct 2026. Keep it honest — a landing page is worthless if the app itself
fails the `security-shipping` and `legal` audits first.
